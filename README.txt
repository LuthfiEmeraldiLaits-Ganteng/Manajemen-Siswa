MANAJEMEN SISWA - VERSI LENGKAP

1. Extract ZIP ini.
2. Buka terminal di folder yang berisi package.json.
3. Jalankan:
   npm install
   npm run dev
4. Buka:
   http://localhost:3000/dashboard

Struktur utama:

- src/app/auth/register/page.tsx

- src/components/ui/layout/ClientLayout.tsx
- src/app/layout.tsx
- src/app/globals.css
- src/app/api/login/route.ts
- src/app/api/register/route.ts
